Project Overview
Katz Hair-do is a hair and beauty salon established in 2026 in Cape Town. Provides haircuts, coloring, braiding, treatments, styling for students, professionals, families, bridal and children.

Goals
1. Create online presence since no official site was found
2. Showcase services
3. Enable online booking/enquiries
4. Show 2 locations for better reach

Key Features
- 5 pages: index, about, services, enquiry, contact
- Semantic HTML5 tags
- Navigation works across all pages
- Enquiry form with validation

Timeline
Week 1: Proposal approval + Content Research 
Week 2: Sitemap and wireframe
Week 3: HTML build testing and GitHub push
